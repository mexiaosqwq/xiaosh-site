技术实现

CSS Flexbox

  • 桌面：flex-direction: row，左侧固定 200px
  • 移动：flex-direction: column，自动堆叠
  • 无需额外框架，纯 CSS 搞定

  • @media (max-width: 640px) 切换布局
  • 移动端缩小头像、减小间距
  • 项目卡片自动填满宽度
