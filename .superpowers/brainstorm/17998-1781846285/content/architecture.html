✅ 约定式路由

  • 主域名 → 直接返回 public/index.html
  • 子域名 snake → 自动找 public/games/snake/index.html
  • 匹配不到的返回 404
  • 加游戏 = 新建文件夹，不动代码

🔌 预留扩展点

  • 自定义路由表（需要特殊处理的路径）
  • API 代理转发
  • 访问统计 / 中间件
